## ⚙️ Tech Stack & Interactive Features

- **Framework**: React 18 with TypeScript & Vite
- **Animations & Scrolling**: GSAP 3, ScrollTrigger, ScrollSmoother, SplitText
- **3D Graphics & Physics**: Three.js, React Three Fiber, React Three Rapier (Physics), Drei
- **Interactive UI**: Magnetic hover effects, custom cursor, interactive physics balls, horizontal project gallery

## 🛠️ Development & Build

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Typecheck and build for production
npm run build

# Preview build locally
npm run preview
```

---

## 📂 Customizing Projects & Assets

1. **Projects**: Edit `src/components/Work.tsx` to add actual case studies, images, and project URLs into the `projects` array.
2. **Project Images**: Place case study screenshots/mockups into `public/images/` and reference them in `Work.tsx`.
3. **Profile Photo**: If adding a photo in addition to the 3D canvas, use the styled `.landing-image` container in `Landing.tsx`.
